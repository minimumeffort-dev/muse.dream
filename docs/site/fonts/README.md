# Documentation fonts

Minimum Effort uses Manrope for body text and Archivo for headings and its wordmark.
These unmodified Latin variable WOFF2 files are served locally by the docs:

- [Manrope, weights 200–800](https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSvfedN4.woff2), from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope). [SIL Open Font License](manrope-OFL.txt).
- [Archivo, weights 100–900](https://fonts.gstatic.com/s/archivo/v25/k3kPo8UDI-1M0wlSV9XAw6lQkqWY8Q82sLydOxKsv4Rn.woff2), from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/archivo). [SIL Open Font License](archivo-OFL.txt).

Retrieved 2026-10-16. System fonts cover glyphs outside these Latin subsets.
