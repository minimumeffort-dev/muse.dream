# Shared category rules, r37

Dream `rule` supplies a shared impact definition to every matching
`measure.kind` before object validation, across the closed linked module graph.
The entry file owns policy. Duplicate category owners and rules inside imported
modules are rejected. The accepted scene keeps the rules and rejects
inconsistent serialized placements.

The live city declares table and bench rules. Their impact parameters match the
existing live furniture, keeping the same 22 reactive placements and 73 potential
fragments. No runtime, physics, animation, particle or rendering budget was raised.
Other object categories retain their current defaults.

The older Wayside bench previously had no destruction. Its existing geometry,
dimensions, material, foundation and supports are retained. A break zone now owns
the seat/back boards and armrests, with back-board bolts attached to their rigid
fragment. A shared `break` rule updates each existing zone's parameters while
preserving retained structure. This library variant is not placed in the live
city. Current slatted benches keep their whole-object fracture construction.
