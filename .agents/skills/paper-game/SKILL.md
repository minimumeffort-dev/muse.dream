# Dreams Lab domain rules

Use with Ponytail full mode. The product is the standalone Lab at the repo root;
the former playable city and its layout have been retired.

Dream describes bounded geometry, systems and task scenarios as validated data.
No generated scripts, eval, model-directed files/URLs or client-side secrets.
Model interpretation and policies remain mocked until explicitly authorized.

The engine owns transitions, conserved resources, capacity, rewards and goals.
Policies see only permitted observations and submit schema-checked actions.
Keep deterministic contention, atomic transfers, private inventories/tasks,
source/seed/version provenance and replay. Rendering cannot set outcomes.

Keep accepted runs separate from drafts and stale async results. Preserve
pause, step, replay, reduced motion, keyboard camera controls and cleanup.
The current 3D view observes logical links; do not claim physical navigation
or clinical, educational, ecological or dataset validity that is not implemented.

Use current Lab tests/build/docs from the repository root. Keep reusable asset
libraries separate from world layouts and mark unsupported definitions clearly.
Do not regenerate or commit screenshots, evidence or capture frames unless
explicitly requested. Update affected guides, then commit and push each slice.
